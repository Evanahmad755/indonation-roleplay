Rules

Server Rules

  1. Dilarang cheat, bug abuse, atau exploit dalam bentuk apapun.
  2. Toleransi terhadap sesama pemain, dilarang toxic di chat maupun voice.
  3. Satu orang hanya boleh punya 1 akun UCP kecuali diizinkan admin.

Roleplay Rules

  1. Wajib RP sesuai karakter, dilarang keluar karakter (OOC) di chat IC tanpa tanda ((...)).
  2. Dilarang Deathmatch (DM) dan Powergaming.
  3. Metagaming (pakai info OOC buat IC) dilarang keras.

Faction & Crime Rules

  1. Faction ilegal wajib RP niat, bukan cuma modal senjata.
  2. Kejahatan besar (rampok bank, dsb) wajib melibatkan minimal RP yang ditentukan.

Chat & Punishment

  1. Dilarang spam / caps lock berlebihan di chat manapun.
  2. Pelanggaran dikenakan sanksi bertahap: Warning → Jail → Kick → Ban, sesuai tingkat keparahan.

*Rules ini masih draf awal, bisa diedit admin kapan aja lewat file dashboard.html.
